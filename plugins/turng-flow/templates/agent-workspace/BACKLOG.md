# BACKLOG.md: work still to do

> This file answers one question: **what is still to do now, and is it scheduled.** Each item uses the 7-field format of the skill `turng-flow:backlog-write`.
> History and the owner's decisions: `agent-workspace/HISTORY.tsv` (ids `H-xxxx`). Inside a task: the folder `agent-workspace/tasks/`.
> The order of items is not a priority order. The owner sets the order of work, in the field "Schedule".
